# Semana 1: Fundamentos del Lenguaje

**Duración:** 5 días  
**Nivel:** Principiante absoluto  
**Objetivo principal:** Construir una base sólida de JavaScript moderno y entender cómo funciona el lenguaje.

---

## 🎯 Objetivos de la Semana

Al finalizar esta semana el estudiante será capaz de:

- Declarar y usar variables correctamente (`const`, `let`)
- Entender los tipos de datos básicos
- Usar operadores y expresiones
- Tomar decisiones con condicionales (`if/else`)
- Repetir código usando bucles (`for`, `while`)
- Crear y usar **funciones** (el tema más importante de esta semana)
- Escribir código limpio, legible y bien estructurado
- Usar `console.log()` efectivamente para depurar

## 📋 Recomendaciones para esta semana

1. **No avances rápido por avanzar.** Es mejor entender bien los fundamentos.
2. Haz **todos los ejercicios** de cada día.
3. Intenta resolver los ejercicios **sin mirar la solución** primero.
4. Usa siempre `const` por defecto. Solo usa `let` cuando realmente necesites reasignar la variable.
5. Escribe código limpio: indentación correcta, nombres claros y comentarios cuando sea necesario.
6. Ejecuta tu código todos los días con `node nombre-del-archivo.js`
