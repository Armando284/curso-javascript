# Curso JavaScript desde Cero → Nivel Junior

Este repositorio contiene un **curso completo y estructurado** de JavaScript diseñado para llevar a estudiantes desde las bases fundamentales hasta un nivel Junior usable en el mercado laboral.

El curso está creado 100% en formato texto, con explicaciones claras, ejemplos y ejercicios prácticos progresivos.

## Objetivos del Curso

- Construir una base sólida de JavaScript moderno
- Desarrollar lógica de programación y capacidad de resolución de problemas
- Aprender buenas prácticas y conceptos esenciales para trabajar como desarrollador Junior
- Preparar al estudiante para continuar con frameworks como React o Node.js

## Duración

**4 meses (16 semanas)**  
Dedicación recomendada: **20-25 horas por semana**

## Requisitos

- Conocimientos básicos de cómo usar una computadora
- Tener instalado [Visual Studio Code](https://code.visualstudio.com/)
- Tener Node.js instalado (versión LTS recomendada)

## Cómo usar este curso

1. Clona el repositorio
2. Sigue las semanas **en orden** (no saltes)
3. Lee la teoría, copia y prueba los ejemplos
4. Completa todos los ejercicios de cada semana
5. Crea tu propia carpeta de soluciones y sube tu código a tu repositorio personal
6. Al final de cada semana, revisa tus dudas con tu mentor
